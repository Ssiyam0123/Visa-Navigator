# Visa Navigator  

Visa Navigator is a user-friendly web portal designed to simplify the visa application process by providing clear information, management tools, and tracking functionality.  

[Live Site URL](https://Ssiyam0123.github.io/Visa-Navigator/)  

## Features  

- **Comprehensive Visa Information**: Access details about various visa types, their requirements, and processes.  
- **CRUD Functionality**: Add, update, delete, and manage visa-related data and user applications.  
- **Authentication & Authorization**: Secure user login, registration, and Google sign-in using Firebase.  
- **Dark Mode Theme**: Toggle between light and dark modes for better accessibility and user experience.  
- **Interactive UI**: Features like responsive design, tooltips, animations (Lottie React), and dynamic visual elements.  
- **Search & Filter**: Easily find and sort visa information using powerful search and filter functionalities.  
- **Real-Time Notifications**: Toast notifications for actions like adding, editing, or deleting data.  

## Tech Stack  

- **Frontend**: React, Tailwind CSS, React Router, Context API.  
- **Backend**: Node.js, Express.js, MongoDB (for data storage).  
- **Authentication**: Firebase (Email/Password and Google Login).  
- **Hosting**: Client hosted on Netlify, server hosted on Vercel.
